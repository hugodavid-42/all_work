# ft_printf ✍️

## Description
This project involves recreating the `printf()` function from the C standard library. The goal is to understand variadic functions and produce a robust implementation of common format specifiers. The `ft_printf()` function handles conversions: `c`, `s`, `p`, `d`, `i`, `u`, `x`, `X`, and `%`.

## Instructions
**Compilation**:
```bash
make
```
**Clean**:
```bash
make clean
make fclean
```
